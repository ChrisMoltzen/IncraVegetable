# Your artwork goes here

Drop images into this folder using the names in `../art_templates/ART_LIST.md`
(keep the sub-folders: `crops/`, `farm/`, `ui/`, ...). For example:

    assets/crops/carrot.png
    assets/ui/coin.png
    assets/tree/icons/patch.png

- Anything you don't provide uses the built-in art, so you can do it one piece at a time.
- PNG with transparency is best. JPG, BMP and TGA also work.
- `../art_templates/` has every image already drawn at the right size with the right
  name. Copy one here and paint over it.
- Press **F5** in the game to reload your art without restarting (desktop).
- Settings like pixel-art scaling are in `art.txt`.
- If a file's name doesn't match anything, the debug screen's Info tab (F1) lists it.
